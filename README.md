# Ventilador inteligente con lógica difusa

Repositorio de trabajo colaborativo para desarrollar un prototipo académico que controle la velocidad de un ventilador según la temperatura de un salón.

Cada integrante creará sus archivos en su propia rama para que GitHub registre claramente su contribución.

## Estructura

```text
├── src/            Código fuente del proyecto
├── tests/          Pruebas y datos de prueba
├── docs/           Secciones del documento
├── evidencias/     Capturas del desarrollo
└── presentation/   Material para la exposición
```
